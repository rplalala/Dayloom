# Engineering evidence

These records preserve consequential decisions, failures, corrections and scoped
validation. Current behavior belongs to the [core designs](../README.md); current
results belong to the [twelve-case benchmark](../../benchmark/README.md).
Read each observation at its recorded date/revision. Local evidence paths are private
historical identifiers, not installation dependencies. Original raw evidence is unchanged;
earlier document versions remain in Git history.
