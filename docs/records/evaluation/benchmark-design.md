# Benchmark responsibility decisions

On 28 September 2026, construction and independent evaluation were separated before
formal case selection. These historical proposals are not the current twelve-case study.
[Benchmark workflow](../../../benchmark/README.md) and [evaluation contracts](../../0006-independent-evaluation.md)
own the current interfaces.

## Accepted responsibility boundary

Construction owned original inputs, complete V0–V3 outputs, selected attempts, usage,
provenance and exclusion reasons. The user selected the evaluation batch. The evaluator
consumed that batch without monitoring candidates, choosing replacements or rerunning planners.
A complete workflow could still contain sparse days, repeats, FAIL or UNKNOWN; a cap alone
was not evidence of resource-truncated execution.

Generic unassigned activities remained transition/free-time rather than invented POIs.
Unresolved named visits retained uncertainty; multiple POIs sharing one visit interval
could not be split by evaluator invention. Exact input/source/configuration hashes and
separate usage ledgers were required; missing usage was not quality failure.

Requirement authoring used complete original input rather than output-selected obligations.
The initial assistant-draft/user-review proposal preceded the later separate-agent handoff.
Tuning exposure, failed attempts and reasons had to remain visible; later success did not
make a previously exposed case held-out or erase earlier consumption.

## Proposals not adopted as execution quotas

The provisional design considered six cities × six request types (36 inputs), with
12 short, 18 medium and six long requests. One run/version meant 144 executions; optional
preselected repeats would yield 192 without extra main-result weight. City exposure,
replacement rules, exact analysis and repeat choice remained open. Candidate cities were
not to be selected using V3 outcomes or only rich retrieval coverage.

A separate controlled Repair proposal used 24 targets/eight controls, outside the four-version
cohort. None of these numbers became automatic evaluator admission rules. Later actual
selections and optional-study boundaries belong to the benchmark, not this proposal.
